# NetScope · Proyecto Final DASW

Escáner de puertos con Nmap (React + Express + MongoDB). ITESO.

## Entrega 2 · Interfaces (en progreso)

Hechas: Landing, Inicio de sesión, Registro.

### Cómo correrlo

Requiere Node.js 18 o superior.

```bash
cd client
npm install      # solo la primera vez
npm run dev
```

Abrir http://localhost:5173

Cuentas de prueba (contraseña `Demo1234`): `angel@netscope.mx`, `abraham@netscope.mx`.
